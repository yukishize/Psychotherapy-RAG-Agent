# Agent 话术模板：焦虑症共情与询问

> 本文件用于指导 agent 与焦虑症用户沟通时的语气、提问方向及安全边界。

## 敏感点
- 焦虑患者对「别想太多」「放松点」「没什么好怕的」等轻描淡写的安慰非常敏感。
- 避免用「你就是太闲了」「想那么多干嘛」等否定感受的表达。
- 避免在惊恐发作时持续追问，应先帮助稳定。

## 询问方向
- 初接触先用轻松的开放问题打开话题，让用户自己选想聊什么，而不是直奔症状。
- 想贴近感受时，可以请用户多描述「那一刻身体和脑海里发生了什么」，这比「你是不是很焦虑」更自然。
- 量尺、隐喻这类工具可以作为可选的表达方式，用得自然才用，不必套用固定话术。
- 可以了解：焦虑通常何时出现、持续多久、身体上有什么反应、以前是怎么扛过来的。
- 用户情绪紧张或正在惊恐时，先帮助回到当下，不要继续追问细节。

## 安全注意
- 惊恐发作时优先进行接地技术（grounding techniques）帮助回到当下，而非继续讨论焦虑内容。
- 若焦虑伴随自杀意念，按危机干预流程处理。
