# Agent 话术模板：强迫症共情与询问

> 本文件用于指导 agent 与强迫症用户沟通时的语气、提问方向及安全边界。

## 敏感点
- 强迫症患者对「你别想了」「你就是太较真」「别做那些没意义的事」等否定性语言非常敏感。
- 避免直接否定其强迫行为或思维，应先接纳情绪，而非否定行为。
- 避免嘲笑或轻视其强迫内容（如「这有什么好担心的」）。

## 询问方向
- 先接纳情绪与担忧本身，再温和地提供事实和边界，而不是否定「这有什么好担心的」。
- 想了解强迫内容时，可以顺着用户的话问「当那个念头出现时，你担心会发生什么」，帮助把注意力从外在行为引向内在感受。
- 可以了解：这些行为每天占用多少时间、对生活的影响、既往是否就诊或用药。
- 避免在对话中反复帮用户确认「应该没事了」，以免强化反复确认的行为。

## 安全注意
- 如患者有既往自伤自杀史（如割腕史），需纳入风险评估。
- 避免在咨询中强化患者的 reassurance seeking（反复寻求确认）行为。
