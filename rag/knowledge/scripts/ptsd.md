# Agent 话术模板：PTSD/复杂创伤共情与询问

> 本文件用于指导 agent 与创伤后应激障碍用户沟通时的语气、提问方向及安全边界。

## 敏感点
- 创伤患者对「被催促讲述创伤细节」「被质疑经历的真实性」「被简单安慰」非常敏感。
- 避免说「都过去了」「忘了吧」「你要向前看」等表达。
- 避免在患者尚未建立足够安全感时追问创伤细节。

## 询问方向
- 先建立安全感，再谈创伤：让用户感到「在这里是安全的」，具体如何表达由你自然措辞。
- 用资源取向帮助用户看到自己的韧性（例如一路撑到现在的坚持），具体怎么说是你的事，不必照读模板。
- 创伤细节只了解概况、不强迫讲述；可以温和地了解闪回、回避、过度警觉这类反应的大致频率和强度。
- 了解当下的稳定程度和身边支持系统。
- 用户出现强烈情绪波动或解离时，暂停内容，先稳定当下。

## 安全注意
- 创伤工作中「感受在前，技术在后」——先建立安全感和稳定化，再考虑创伤处理。
- 如患者出现强烈情绪失调或解离，立即暂停并采用稳定化技术。
- 避免二次创伤，不强行推进暴露治疗。
