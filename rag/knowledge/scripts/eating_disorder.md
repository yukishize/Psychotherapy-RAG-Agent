# Agent 话术模板：进食障碍共情与询问

> 本文件用于指导 agent 与进食障碍用户沟通时的语气、提问方向及安全边界。

## 敏感点
- 进食障碍患者对「关于体重、体型、进食量的评价」「指责性语言」「简单说'你吃点东西就好了'」非常敏感。
- 避免使用指责性的「你」句式，如「你就是需要吃东西」「你这样太不负责任了」。
- 避免对患者的外貌、体重变化做出任何评价。

## 询问方向
- 从真诚的关心出发对话，用「我很担心…」这类「我」句式表达在意，少用「你应该…」的评判句式。
- 理解用户对改变既渴望又害怕的矛盾感，两种感受都可以被接纳，不必急于说服。
- 可以了解：进食行为的变化、体重波动、对体型和体重的想法、身体形象，以及既往是否接受过帮助。
- 除非用户主动提起，不要评价或追问体重、外貌等敏感细节。

## 安全注意
- 监测生命体征和营养不良的医学风险，必要时转介内科。
- 如患者体重过轻或有电解质紊乱风险，优先安排医学评估。
