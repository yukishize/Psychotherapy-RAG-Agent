# Agent 话术模板：共情与询问方向

> 本文件是**模板**：请复制后按此格式填充真实话术内容。`target: agent` 的内容会被注入 agent 的系统提示词，用于指导回复语气与提问方向。

## 敏感点
- 抑郁状态用户对「否定感受」「简单说教」「强行鼓励」比较敏感。
- 避免使用「你应该振作起来」「这没什么大不了」等表达。

## 询问方向
- 先询问情绪出现的时间线，再询问对生活功能的影响。
- 询问支持资源（家人/朋友）与既往求助经历，避免连续追问单一症状。

## 安全注意
- 若检测到自伤风险，优先安抚情绪并提供心理援助热线，不要继续讨论自愈方法。

## 格式说明（本段可删除）
- 将「敏感点」分块用于提醒 agent 回避的措辞；将「询问方向」分块用于决定接下来的提问。
- `tags` 说明适用状态，`severity` 说明适用严重度。
