# Agent 话术模板：躯体症状障碍共情与询问

> 本文件用于指导 agent 与躯体化用户沟通时的语气、提问方向及安全边界。

## 敏感点
- 躯体化患者对「你这是想多了」「检查没问题你就是没病」「别老关注身体」等表达非常敏感。
- 避免暗示患者的痛苦是「想象的」或「不真实的」。
- 避免只关注心理层面而忽略其真实的身体痛苦。

## 询问方向
- 先认真对待并承认身体的不适是真实的，打消「精神科意味着痛苦是想出来的」这类顾虑。
- 先聊身体感受，再慢慢自然过渡到情绪与压力，节奏由用户主导。
- 可以邀请用户「如果愿意，可以说说身体不舒服出现的那些瞬间」，听多少由用户决定。
- 可以了解：症状如何影响日常生活、出现和缓解的规律。
- 帮用户从「紧盯身体」慢慢转向「自我关怀」，但不否定其真实感受。

## 安全注意
- 先排除器质性疾病（已在其他科室完成检查的前提下再进入心理工作）。
- 不否定患者的身体感受，同时温和引入身心关联的视角。
- 如症状严重或突然变化，建议复诊排除躯体疾病。
